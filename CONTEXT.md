# Ziqi Tab

Ziqi Tab is a browser new-tab extension evolving into a personal dashboard. It keeps common, glanceable information and launch points together at the start of a browsing session.

## Language

**Dashboard**:
The new-tab experience that combines configurable information, actions, and launch points in one personal workspace.
_Avoid_: Start page, home page

**Dashboard Module**:
A self-contained dashboard capability, such as Recent Browsing, with its own visibility and presentation settings.
_Avoid_: Widget, card

**Settings**:
The dedicated workspace where a person configures dashboard content, behavior, and stored data.
_Avoid_: Preferences panel

**Recent Browsing**:
A dashboard module that surfaces distinct websites a person has visited recently as return-entry points.
_Avoid_: History, browsing log

**Todo**:
A dashboard module for recording and completing a person's next actions.
_Avoid_: Task manager, checklist

**Archive**:
A Todo dialog tab holding completed Todos until a person restores or permanently deletes them.
_Avoid_: Completed list, trash
